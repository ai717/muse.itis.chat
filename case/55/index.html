用 Muse 搭全自动薅羊毛流水线：自动扫描、自动领取、自动入库

三步拼装出一条不用自己操心的薅羊毛流水线：先建一个「免费资源」空间当仓库；再把一条任务提示词丢给 Muse，让它在 VPS 上装一台常驻 Chrome 当领取专用浏览器；最后装一个 24 小时运行的羊毛情报空间负责全网扫描。扫到高价值免费资源后，用浏览器里保存的 Google 登录状态自动注册领取，领取成功自动归档进资源空间。作者晒出的资源空间里已有 11 项已获取资源。
任务背景
2026-11-13 15:04，Anis（@Yonkxx）在 X 发帖给出完整拼装法。他在 11-12 先发过一条「把链接丢给 Muse、让它在 VPS 上装好 Chrome 并登录 Google」的提示词帖（25,066 浏览），本帖再把它与 @wlzh 11-09 长帖的羊毛情报空间方案拼成全自动流水线。本帖是狗爸爸投稿，经总管核验后直发收录。
做法步骤 (4 步)
  1. 1. 第一步建仓库空间：创建一个名为「免费资源」的空间（Space），以后自动领取的 VPS、GPU 等免费资源统一入库到这里。
  2. 2. 第二步装领取专用浏览器：把作者 11 月 12 日那条帖子的链接丢给 Muse，让它在 VPS 上装 Google Chrome、Xvfb 虚拟显示与中文字体，做成 systemd 常驻服务（开机自启、崩溃自动拉起）；远程调试端口 9222 与 VNC 都只绑 127.0.0.1、经 SSH 隧道访问；Chrome 用独立用户数据目录保存登录状态，本人经 VNC 登录一次 Google，之后登录态长期复用。
  3. 3. 第三步装情报空间：把 @wlzh 的帖子链接丢给 Muse，装「GLOBAL DEAL HUNTER｜全球羊毛情报中心」空间——每 2 小时全网扫描 AI 订阅优惠、Crypto、U 卡、海外银行、VPS 及云服务等类别，自动去重、核有效期、算价值、分看板展示，每天 4 次定时推送。
  4. 4. 第四步拼成流水线：情报空间扫到高价值羊毛后，Muse 调用 VPS 上已登录的 Chrome 自动注册并领取，领取成功自动写入「免费资源」空间归档，全程不用人盯。
关键提示词 (Prompt)
PROMPT TEMPLATE
（核心指令摘录，原帖引用帖任务原文的浓缩）「帮我在这台 VPS 上装一个长期可用的『领取专用浏览器』：Chrome 做成常驻服务、登录状态存独立目录、调试端口只绑本机；我经 VNC 登录一次，之后需要 Google 登录的操作，你直接用这台浏览器做。」
产出与证据
作者晒出的「免费资源」空间截图：11 项已获取资源、11 项已部署，其中含 3 个 GPU 资源。截图里可辨认的两张卡片：InstaBox 免费云电脑（4 vCPU、8 GiB 内存、20 GiB 磁盘，Linux，卡片注明 2026-11-13 经 Google 账号注册领取，状态运行中）与 ModelScope 魔搭社区 AMD GPU 环境（192 GB 显存、100 小时免费额度，2026-11-11 领取）。热度为总管 2026-11-14 实读原帖：14,012 浏览、153 赞、222 收藏、16 转帖。
复现要点
1. 先分开跑通再拼装：常驻浏览器、情报空间、资源空间各自验收后，再串成流水线，出问题好定位。2. 安全底线照原帖守：调试端口与 VNC 只绑 127.0.0.1、走 SSH 隧道；密码与验证码自己经 VNC 输入，不要发在聊天里。3. SSH 密钥文件设 600 权限；领取用的 Google 账号建议用专用号，不要拿主力账号自动跑。4. 免费活动规则变得快，自动领取前先让 Muse 核一遍活动是否仍有效、条件是否还对得上。
踩坑提示
1. 诚实标注：「全自动领取」环节为作者自述，帖内没有自动化运行日志或领取回执可核；截图只能证明资源空间里已有 11 项资源清单，其中 ModelScope 一项卡片注明由作者本人参加 AMD 激励计划领取，并非全部由流水线自动完成。2. 用保存登录状态的浏览器自动注册领取，可能触碰目标平台的自动化条款，有封号风险，先用小号小规模试。3. 情报空间来自第三方帖子的方案，扫描覆盖与验真质量以原帖为准，重要领取前回官方页面核对。
