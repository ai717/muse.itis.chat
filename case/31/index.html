临出发才规划纽约亲子游：Muse 在一个对话里订好停车、渡轮票和酒店

一个对话订完一趟自驾亲子游的全部零碎预订，还会按体力安排顺路停靠。
任务背景
Rajesh Akinepalli 带父亲去纽约旅行，机票几周前就订好了，其他一切拖到最后一刻毫无计划。临行前他把整趟行程交给 Muse 在同一个对话里逐项搞定：市区停车、轮渡票、沿途酒店，都不用在多个 App 之间来回拼凑。
做法步骤 (5 步)
  1. 1. 把父子同行、时间紧、怕累等约束一次告诉 Muse
  2. 2. 在同一个对话里先订曼哈顿停车位
  3. 3. 接着订自由女神像渡轮票，再订自驾沿途酒店
  4. 4. 让它按驾驶强度插入 Letchworth State Park 等顺路停靠点
  5. 5. 自己复核机场摆渡等关键班次信息后出发
产出与证据
Muse 在一个对话里接连订好曼哈顿的停车位、去自由女神像的渡轮票和自驾沿途的酒店；它还顾及了父子俩的时间约束和长途驾驶的体力，建议了 Letchworth State Park 这类顺路的停靠点。整趟行程不到两天全部玩完。
复现要点
把同行人、体力约束、必去点和预算一次说清，让 Muse 在一个对话里连续订停车、门票和酒店；涉及机场接驳和班次时刻的结果务必去官网二次核对。
踩坑提示
它推荐的一班 Newark 机场到 LaGuardia 的摆渡车根本不存在，差点误事；线上订渡轮票为保确认名额价格偏高，现场其实没什么人。交通时刻类信息必须自己再核一遍。
