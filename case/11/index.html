YouTube 实测：用 5 美元档 Muse Wonder 从零搭全栈网站，界面惊艳但登录有坑

一次提示让 Muse Wonder 生成带数据库与登录的全栈站点只要几分钟，但认证与 Cookie 必须人工验。

🎯 任务背景
博主想实测刚发布的 Muse Wonder 编程能力到底行不行，选了最能暴露问题的任务：从零做一个带数据库和用户认证的完整网站，而不是静态页面。
📝 做法步骤 (5 步)
  1. 1
    开通视频中使用的 5 美元 Muse Coding 档位并完成设置
  2. 2
    写好测试提示词，指定技术栈：Astro + Tailwind CSS 建站、Drizzle ORM + LibSQL 做数据库、Better Auth 做登录
  3. 3
    观看 Muse 自主搭建全过程（视频 3:28 起完整呈现构建过程）
  4. 4
    从界面设计与 SVG 生成质量、登录流程、Cookie 与自主自测四个方面逐项验收
  5. 5
    对暴露的认证问题现场追问修复（视频 8:06 起记录追 Bug 与 9:21 起现场改的过程）
📊 产出与证据
视频完整记录产出：一个从零生成的全栈网站，作者评价其 UI 设计与 SVG 生成出乎意料地精致；同时有明确的产出证据链——章节时间戳标出「构建 4 分钟但零自测」、登录 Bug 排查与现场修复全过程，结论部分（12:18 起）汇总其上限与限制。
💡 复现要点
需要 Muse Coding 付费档与一个明确的技术栈提示词；验收重点放在登录、Cookie 等看不见的底层环节，不要只看界面。
⚠️ 踩坑提示
视频实测指出：Muse 搭完 4 分钟却完全没有自测，认证与 Cookie 环节藏有真实 Bug，需要人工追查修复后才能用。
