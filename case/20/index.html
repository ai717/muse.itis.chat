零代码一晚做出在线决策工具：博主喂自己全部内容让 Muse 建站

把多年内容喂成知识库再多轮磨逻辑，不写代码也能上线一个真能用的专业小工具。

🎯 任务背景
广告营销博主 Jon Loomer 想做一个帮广告主判断该不该用价值规则的决策工具，内容基础是他多年讲价值规则的文章、视频与播客稿，但他不想写代码、更不想雇开发。
📝 做法步骤 (5 步)
  1. 1
    先让 Muse（作者取名 Frank）调研自己当年的全部内容，给出可做工具的选题建议
  2. 2
    从 3 个初版想法中砍掉两个想做太多的，最终选定 Value Rules Decision Tool
  3. 3
    把博客文章、视频帖、播客脚本再加一份自写的 Master Brief 喂给 Muse 建知识库
  4. 4
    多轮迭代：逐项争论并修正不合预期的逻辑与多余步骤，直到流程顺手
  5. 5
    以添加 HTML 并更新自定义 CSS 的方式把工具嵌到自己页面上线
📊 产出与证据
原文记录产出：名为 Value Rules Decision Tool 的在线工具已在其站点上线可用（引导用户逐项走完所用限制与条件、最后给出是否该用价值规则的结论）；作者明确说是在一个晚上做完的、全程零代码，但也坦言还不是成品、只是大体符合预期。同文另有已落地的用法：让其代理 Frank 每周一早上检查 Meta 帮助中心与开发者页面的变更。
💡 复现要点
桌面端使用更顺手；先把自己的文章、脚本与一份总纲文件喂成知识库再开工；上线方式可选 iframe 嵌入或 HTML 加自定义 CSS，作者选了后者。
⚠️ 踩坑提示
原文坦言过程并不省心：逻辑不按预期走、无用步骤等问题来回争执多轮，需要作者给出大量细致想法反复迭代，不要指望一句话出成品。
